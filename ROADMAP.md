# Roadmap

## v0.1.0 (current)

First MVP release.

- Interactive `init` wizard
- `agent:add`, `agent:list`, `agent:start`, `agent:stop`
- Local install directory creation
- Remote deploy script generation
- Family template with 4 example agents
- Tests and GitHub Actions CI
- MIT license

## v0.2.0

- `deploy` command: one-click push to remote VPS via SSH
- Official MCPL plugin downloader (Discord, heartbeat, shell)
- `upgrade` command: bump `@animalabs/*` dependencies
- `agent:remove` command

## Future

- Web dashboard (Studio)
- More templates: `single-agent`, `team`, `knowledge-miner`
- macOS launchd support
- Backup / restore agent memory
- Multi-host fleet management
